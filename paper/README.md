# Paper: arXiv manuscript

An arXiv-ready LaTeX manuscript reporting the controlled tokenizer-compression
study. Every number is drawn from the repository's claim registry
(`../publication/claims.yaml`) and reconciled by `make verify-claims`.

## Build

```bash
uv run python ../scripts/make_tables.py   # regenerate tables from result files
make paper                                # -> arxiv/build/main.pdf (pdflatex + bibtex)
make check                                # citation/reference/undefined checks
make arxiv                                # clean source archive (does NOT submit)
```

Requires a TeX distribution (pdflatex, bibtex). Figures are vector PDFs in
`figures/` (regenerated by `../scripts/make_figures.py`). Bibliography is
`references.bib` (verified citations only; see `literature/`).

## Layout

- `main.tex` — document; `\input`s `sections/*.tex` and `appendix/*.tex`.
- `sections/` — abstract, introduction, related work, RQs, data, methodology,
  results, analysis, limitations, ethics, future work, conclusion.
- `tables/` — LaTeX tables generated from `results/` + the claim registry.
- `figures/` — vector PDF figures (source tables in `results/tables/`).
- `metadata/` — title, abstract, author metadata (`authors.yaml`), arXiv categories.
- `arxiv/` — packaging (submission checklist, manifest, build) — see Phase G.
